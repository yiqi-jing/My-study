# R语言课堂笔记
## 一、基础语法
### 1. 注释
- 单行注释：`#`
- 多行注释：`''''`

### 2. 变量命名规则
- 组成：字母、数字、下划线、点
- 约束：不能以数字/下划线开头；区分大小写；禁用保留字；点开头后不能跟数字
- 推荐：驼峰命名`myVariableName`、下划线命名`my_variable_name`

### 3. 赋值运算符
- 向左赋值：`<-`（推荐）、`<<-`、`=`
- 向右赋值：`->`、`->>`
- 示例：`x <- 2`、`2 -> x`

### 4. 运算符
#### 基本运算
`+`、`-`、`*`、`/`、`^`（幂）、`%%`（取余）、`%/%`（整除）

#### 关系运算
`==`、`!=`、`>`、`<`、`>=`、`<=`，返回`TRUE/FALSE`

#### 逻辑运算
- `&`：与（两边都执行）
- `|`：或
- `!`：非
- `&&`：短路与（左假右不执行）
- `||`：短路或（左真右不执行）

### 5. 常用函数
- `sqrt(n)`：平方根
- `abs(n)`：绝对值
- `round(n, digits)`：四舍五入
- `ceiling(n)`：上取整
- `floor(n)`：下取整
- `exp(n)`：e的n次幂
- `log(n, base)`：对数（默认自然对数）
- `length(x)`：对象长度

## 二、数据类型
### 1. 基本类型
- 数字
- 文本（字符串，单/双引号包裹）
- 逻辑值（`TRUE`/`FALSE`）

### 2. 对象类型
#### 向量（vector）
- 创建：`c()`，同一向量类型一致
- 示例：`v1 <- c(1,2,3)`
- 访问：`v1[1]`（下标从1开始）

#### 列表（list）
- 创建：`list()`，可存任意类型
- 示例：`my_list <- list(1, "a", TRUE)`
- 访问：`my_list[[1]]`
- 删除：赋值`NULL`

#### 矩阵（matrix）
- 创建：`matrix(data, nrow, ncol)`
- 访问：`m[1,2]`
- 运算：`%*%`（矩阵乘法）、`t()`（转置）、`solve()`（求逆）

#### 数组（array）
- 创建：`array(data, dim=c(行,列,维))`
- 访问：`arr[1,2]`

#### 因子（factor）
- 用途：分类数据
- 创建：`factor(x, levels=c())`

#### 数据框（data.frame）
- 用途：表格数据，列可不同类型
- 创建：`data.frame(col1=c(), col2=c())`
- 访问：`df[1,2]`、`df$col`
- 合并：`rbind()`（行）、`cbind()`（列）
- 管道：`%>%`

## 三、流程控制
### 1. 条件语句
#### if-else
```r
if (condition) {
  代码
} else {
  代码
}
```

#### switch
```r
switch(expression,
       case1={代码},
       case2={代码},
       default={代码})
```

### 2. 循环语句
#### for循环
```r
for (i in sequence) {
  代码
}
```

#### while循环
```r
while (condition) {
  代码
}
```

#### repeat循环
```r
repeat {
  代码
  if (condition) break
}
```

### 3. 循环控制
- `break`：退出循环
- `next`：跳过当前轮次
