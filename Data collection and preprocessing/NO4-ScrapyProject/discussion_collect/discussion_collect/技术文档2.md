# 三、数据清洗过程及其结果
## 3. 异常值与噪声数据处理
### 3.1 等宽分箱并用均值平滑
#### 3.1.1 方法原理
等宽分箱是将数值型数据的取值范围按固定宽度划分为若干区间（分箱），每个分箱的区间宽度相等。均值平滑是用每个分箱内所有数据的均值替换箱内各数据值，以降低异常值对数据分布的影响，使数据更平滑。

#### 3.1.2 核心代码
```python
import pandas as pd
import numpy as np

class EqualWidthBinning:
    def __init__(self, bins=4):
        self.bins = bins  # 分箱数量
        self.bin_means = {}  # 存储每个分箱的均值
    
    def perform_equal_width_binning_with_mean_smooth(self, data, field_name):
        # 过滤无效值并转换为数值型
        numeric_data = pd.to_numeric(data, errors='coerce').dropna().astype(int)
        if len(numeric_data) == 0:
            print(f"字段「{field_name}」无有效数值，跳过处理")
            return
        
        # 等宽分箱（左闭右开区间）
        cuts = pd.cut(numeric_data, bins=self.bins, right=False)
        bin_counts = pd.value_counts(cuts).sort_index()
        bin_values = [numeric_data[cuts == bin] for bin in bin_counts.index]
        
        # 构建分箱矩阵
        max_count = bin_counts.max()
        width_matrix = np.full((self.bins, max_count), 0)
        for i in range(self.bins):
            bin_data = bin_values[i]
            for j in range(len(bin_data)):
                width_matrix[i, j] = bin_data[j]
        
        # 均值平滑处理
        mean_matrix = np.full((self.bins, max_count), 0)
        for i in range(self.bins):
            bin_data = bin_values[i]
            if len(bin_data) == 0:
                continue
            bin_mean = int(np.mean(bin_data))  # 计算分箱均值
            self.bin_means[f"分箱{i+1}"] = bin_mean
            for j in range(len(bin_data)):
                mean_matrix[i, j] = bin_mean  # 用均值替换箱内数据
        
        # 输出结果
        print(f"\n【{field_name} - 等宽分箱结果】")
        print("分箱区间:", list(bin_counts.index))
        print("分箱矩阵:")
        print(width_matrix)
        print(f"\n【{field_name} - 均值平滑结果】")
        print(mean_matrix)
        print(f"\n各分箱均值: {self.bin_means}")
        return mean_matrix
```

#### 3.1.3 实现步骤
1. 数据预处理：过滤“未获取到信息”等无效值，将目标字段转换为int类型；
2. 等宽分箱：使用`pd.cut()`函数按指定分箱数划分区间（左闭右开），统计每个区间的样本数量；
3. 构建分箱矩阵：以样本数最多的分箱为基准，构建规整的分箱矩阵（不足部分补0）；
4. 均值平滑：计算每个分箱的均值，用均值替换对应分箱内的所有数据值；
5. 输出结果：打印分箱区间、原始分箱矩阵和均值平滑后的矩阵。

#### 3.1.4 处理结果
- 针对“总评论数”“阅读量”字段各划分4个等宽区间，例如“阅读量”区间可能为`[0, 5000), [5000, 10000), [10000, 15000), [15000, 20000)`；
- 成功计算每个分箱的均值并完成平滑替换，例如“总评论数”某分箱原始数据`[8, 12, 15, 9]`，均值为11，平滑后变为`[11, 11, 11, 11]`；
- 有效降低了异常值对数据分布的干扰，使数据趋势更清晰。

### 3.2 等深分箱并用中位数平滑
#### 3.2.1 方法原理
等深分箱（也叫等频分箱）是将数值型数据按样本数量均分，每个分箱包含近似相等的样本数，避免因数据分布不均导致部分分箱样本过多或过少的问题。中位数平滑是用每个分箱内数据的中位数替换箱内各数据值，中位数对异常值更稳健，平滑效果更可靠。

#### 3.2.2 核心代码
```python
import pandas as pd
import numpy as np
import math

class EqualDepthBinning:
    def __init__(self, bin_depth=20):
        self.bin_depth = bin_depth  # 每个分箱的样本数量
        self.bin_medians = {}  # 存储每个分箱的中位数
    
    def perform_equal_depth_binning_with_median_smooth(self, data, field_name):
        # 过滤无效值并转换为数值型
        numeric_data = pd.to_numeric(data, errors='coerce').dropna().astype(float)
        if len(numeric_data) == 0:
            print(f"字段「{field_name}」无有效数值，跳过处理")
            return
        
        # 数据排序（等深分箱前提）
        sorted_data = np.sort(numeric_data)
        total_samples = len(sorted_data)
        
        # 计算分箱数并补齐数据（确保总样本数为bin_depth的整数倍）
        bin_count = math.ceil(total_samples / self.bin_depth)
        pad_length = (bin_count * self.bin_depth) - total_samples
        padded_data = np.pad(sorted_data, (0, pad_length), mode='edge')  # 边缘值补齐
        
        # 等深分箱（按深度拆分）
        depth_bins = padded_data.reshape(bin_count, self.bin_depth)
        
        # 中位数平滑处理
        median_depth = np.full(depth_bins.shape, 0.0)
        for i in range(bin_count):
            bin_median = np.median(depth_bins[i])  # 计算分箱中位数
            self.bin_medians[f"分箱{i+1}"] = bin_median
            median_depth[i] = bin_median  # 用中位数替换箱内所有数据
        
        # 输出结果
        print(f"\n【{field_name} - 等深分箱原始结果】")
        print(depth_bins)
        print(f"\n【{field_name} - 中位数平滑结果】")
        print(median_depth)
        print(f"\n各分箱中位数: {self.bin_medians}")
        print(f"分箱统计：分箱数={bin_count}，每个分箱样本数={self.bin_depth}")
        return median_depth
```

#### 3.2.3 实现步骤
1. 数据预处理：过滤无效值，将目标字段转换为float类型，确保数值一致性；
2. 数据排序：对有效数值按升序排序，为等深分箱奠定基础；
3. 分箱数量计算：根据总样本数和预设分箱深度，计算分箱数，并用边缘值补齐数据（使总样本数为分箱深度的整数倍）；
4. 等深分箱：将排序后的数据按分箱深度拆分为若干分箱，形成分箱矩阵；
5. 中位数平滑：计算每个分箱的中位数，用中位数替换对应分箱内的所有数据值；
6. 输出结果：打印原始分箱矩阵、中位数平滑后的矩阵及分箱统计信息。

#### 3.2.4 处理结果
- 每个分箱固定包含20条样本，例如“总评论数”有效样本1980条，共划分99个分箱；
- 中位数平滑后的数据保留了数据的整体分布趋势，同时屏蔽了异常值的影响，例如某分箱原始数据`[5, 7, 200, 12, 9]`，中位数为9，平滑后变为`[9, 9, 9, 9, 9]`；
- 分箱结果均匀，无样本分布失衡问题，为后续分析提供了更可靠的数据基础。

## 7. 规范化
规范化是将数值型数据缩放到统一区间，消除不同字段的量纲差异，使数据具有可比性，为后续建模（如聚类、回归分析）提供标准化输入。本次实现三种经典规范化方法，均基于噪声处理后的数据集（`fedora_centos_topics_noise_replaced.csv`）。

### 7.1 Min-Max规范化（最小-最大规范化）
#### 7.1.1 方法原理
Min-Max规范化将数据线性映射到指定区间（默认`[0, 1]`），公式如下：
$$x' = \frac{x - \text{min}(x)}{\text{max}(x) - \text{min}(x)} \times (\text{target_max} - \text{target_min}) + \text{target_min}$$
其中：
- $x$ 为原始数据；
- $\text{min}(x)$、$\text{max}(x)$ 为原始数据的最小值和最大值；
- $\text{target_min}$、$\text{target_max}$ 为目标区间的最小值和最大值（默认0和1）。

#### 7.1.2 核心代码
```python
import pandas as pd
import numpy as np
import os

class MinMaxNormalization:
    def __init__(self, target_range=(0, 1)):
        self.target_min, self.target_max = target_range  # 目标区间
        self.normalize_stats = {}  # 存储规范化统计信息
    
    def process_min_max_normalization(self, df, numeric_fields):
        df_copy = df.copy()
        invalid_placeholder = '未获取到信息'
        
        for field in numeric_fields:
            # 分离有效数值和无效值
            valid_mask = (df_copy[field] != invalid_placeholder)
            valid_series = pd.to_numeric(df_copy.loc[valid_mask, field], errors='coerce').dropna()
            
            # 统计有效/无效数量
            valid_count = len(valid_series)
            invalid_count = len(df_copy) - valid_count
            self.normalize_stats[field] = {
                'valid_count': valid_count,
                'invalid_count': invalid_count,
                'original_min': None,
                'original_max': None,
                'mean_after_norm': None
            }
            
            if valid_count == 0:
                print(f"字段「{field}」无有效数值，跳过规范化")
                continue
            
            # 计算原始数据极值
            original_min = valid_series.min()
            original_max = valid_series.max()
            self.normalize_stats[field]['original_min'] = original_min
            self.normalize_stats[field]['original_max'] = original_max
            
            # 处理极值相同的情况（避免除零错误）
            if original_max == original_min:
                df_copy.loc[valid_mask, field] = self.target_min
                self.normalize_stats[field]['mean_after_norm'] = self.target_min
                continue
            
            # Min-Max规范化核心计算
            def normalize_func(x):
                if x == invalid_placeholder:
                    return invalid_placeholder
                try:
                    val = float(x)
                    normalized_val = (val - original_min) / (original_max - original_min) * (self.target_max - self.target_min) + self.target_min
                    return round(normalized_val, 6)  # 保留6位小数
                except:
                    return invalid_placeholder
            
            # 应用规范化
            df_copy[field] = df_copy[field].apply(normalize_func)
            
            # 计算规范化后的均值
            norm_valid_series = pd.to_numeric(df_copy.loc[valid_mask, field], errors='coerce').dropna()
            self.normalize_stats[field]['mean_after_norm'] = norm_valid_series.mean()
        
        return df_copy, self.normalize_stats
```

#### 7.1.3 实现步骤
1. 数据加载：读取噪声处理后的CSV文件，验证目标字段（总评论数、阅读量）是否存在；
2. 有效数据筛选：分离每个字段的有效数值和无效值（标识为“未获取到信息”），过滤无法转换为数值的异常值；
3. 极值计算：计算每个字段有效数据的最小值和最大值；
4. 规范化计算：应用Min-Max公式将数据映射到`[0, 1]`区间，处理极值相同的边界情况（避免除零错误）；
5. 结果统计：计算规范化后的均值、有效/无效数据量等统计信息；
6. 输出结果：返回规范化后的数据集和统计信息。

#### 7.1.4 处理结果
- 规范化后“总评论数”“阅读量”字段的数值均落在`[0, 1]`区间内；
- 统计示例：“阅读量”原始范围`[100, 19800]`，规范化后均值`0.325689`，最小值`0.0`，最大值`1.0`；
- 有效保留了原始数据的相对分布关系，消除了量纲差异，适用于对数据范围有明确要求的建模场景。

### 7.2 Z-Score规范化（标准化）
#### 7.2.1 方法原理
Z-Score规范化将数据转换为标准正态分布（均值≈0，标准差≈1），突出数据的相对位置，公式如下：
$$z = \frac{x - \mu}{\sigma}$$
其中：
- $x$ 为原始数据；
- $\mu$ 为原始数据的均值；
- $\sigma$ 为原始数据的标准差。

#### 7.2.2 核心代码
```python
import pandas as pd
import numpy as np
import os

class ZScoreNormalization:
    def __init__(self):
        self.invalid_values = ['未获取到信息', 'N/A', '', ' ', 'NaN', 'None']  # 无效值标识
    
    def z_score_normalization(self, df, numeric_fields):
        df_normalized = df.copy()
        df_normalized = df_normalized.replace(self.invalid_values, np.nan)  # 替换无效值为NaN
        
        for field in numeric_fields:
            print(f"\n----- 对字段「{field}」执行Z-Score归一化 -----")
            # 提取有效数值
            numeric_series = pd.to_numeric(df_normalized[field], errors='coerce').dropna()
            if len(numeric_series) == 0:
                print(f"  字段「{field}」无有效数值，跳过归一化")
                continue
            
            # 计算均值和标准差
            mean_val = numeric_series.mean()
            std_val = numeric_series.std()
            print(f"  原始数据统计：均值={mean_val:.2f}，标准差={std_val:.2f}")
            
            # 处理标准差为0的边界情况（所有数值相同）
            if std_val < 1e-6:
                print(f"  警告：字段「{field}」所有有效数值相同，归一化后均为0")
                def normalize_func(x):
                    return 0.0 if not pd.isna(x) else "未获取到信息"
            else:
                # Z-Score核心计算
                def normalize_func(x):
                    if pd.isna(x):
                        return "未获取到信息"
                    try:
                        val = float(x)
                        return round((val - mean_val) / std_val, 4)  # 保留4位小数
                    except:
                        return "未获取到信息"
            
            # 应用规范化
            df_normalized[field] = df_normalized[field].apply(normalize_func)
            print(f"  归一化完成：有效数值条数={len(numeric_series)}")
        
        return df_normalized
```

#### 7.2.3 实现步骤
1. 数据加载：读取噪声处理后的CSV文件，将无效值替换为NaN便于筛选；
2. 有效数据提取：过滤每个字段的NaN和非数值数据，得到有效数值序列；
3. 统计量计算：计算有效数据的均值（$\mu$）和标准差（$\sigma$）；
4. 规范化计算：应用Z-Score公式进行标准化，处理标准差接近0的边界情况（所有数值相同时归一化为0）；
5. 结果还原：将NaN还原为“未获取到信息”，保留无效值标识；
6. 输出结果：返回规范化后的数据集，打印每个字段的统计信息和前15条数据示例。

#### 7.2.4 处理结果
- 规范化后“总评论数”“阅读量”字段的均值≈0，标准差≈1，例如“总评论数”归一化后均值`0.0231`，标准差`0.9876`；
- 数据呈标准正态分布，便于识别异常值（通常|z|>3的为异常值）；
- 不改变数据的分布形态，仅消除量纲影响，适用于对数据分布有正态假设的建模场景（如线性回归、聚类分析）。

### 7.3 小数定标规范化
#### 7.3.1 方法原理
小数定标规范化通过10的幂次缩放将数据映射到`[-1, 1]`区间，无需依赖数据分布，仅通过最大绝对值动态调整缩放系数，公式如下：
$$x' = \frac{x}{10^j}$$
其中：
- $x$ 为原始数据；
- $j$ 为满足 $10^{j-1} \leq \text{max_abs}(x) < 10^j$ 的最小整数（$\text{max_abs}(x)$ 为原始数据的最大绝对值）。

#### 7.3.2 核心代码
```python
import pandas as pd
import numpy as np
import os

class DecimalScalingNormalization:
    def __init__(self):
        self.invalid_values = ['未获取到信息', 'N/A', '', ' ', 'NaN', 'None']  # 无效值标识
        self.scaling_info = {}  # 存储缩放信息（最大绝对值、j值、缩放因子）
    
    def decimal_scaling_normalization(self, df, numeric_fields):
        df_normalized = df.copy()
        df_normalized = df_normalized.replace(self.invalid_values, np.nan)
        
        for field in numeric_fields:
            print(f"\n----- 对字段「{field}」执行小数定标归一化 -----")
            # 提取有效数值
            numeric_series = pd.to_numeric(df_normalized[field], errors='coerce').dropna()
            if len(numeric_series) == 0:
                print(f"  字段「{field}」无有效数值，跳过归一化")
                self.scaling_info[field] = {'max_abs': None, 'j': None, 'scaling_factor': None}
                continue
            
            # 计算最大绝对值和缩放系数j
            max_abs = numeric_series.abs().max()
            if max_abs == 0:
                j = 1
                print(f"  所有有效数值均为0，归一化后保持为0")
            else:
                j = int(np.ceil(np.log10(max_abs))) if max_abs >= 1 else 0
            scaling_factor = 10 ** j  # 缩放因子：10^j
            
            # 存储缩放信息
            self.scaling_info[field] = {
                'max_abs': max_abs,
                'j': j,
                'scaling_factor': scaling_factor
            }
            
            print(f"  原始数据统计：最大绝对值={max_abs:.2f}")
            print(f"  缩放参数：j={j}，缩放因子=10^{j}={scaling_factor}")
            
            # 小数定标核心计算
            def normalize_func(x):
                if pd.isna(x):
                    return "未获取到信息"
                try:
                    val = float(x)
                    return round(val / scaling_factor, 4)  # 保留4位小数
                except:
                    return "未获取到信息"
            
            # 应用规范化
            df_normalized[field] = df_normalized[field].apply(normalize_func)
            print(f"  归一化完成：有效数值条数={len(numeric_series)}")
        
        return df_normalized, self.scaling_info
```

#### 7.3.3 实现步骤
1. 数据加载：读取噪声处理后的CSV文件，将无效值替换为NaN；
2. 有效数据提取：过滤每个字段的NaN和非数值数据，得到有效数值序列；
3. 缩放系数计算：计算有效数据的最大绝对值，确定缩放系数$j$和缩放因子$10^j$；
4. 规范化计算：应用小数定标公式将数据缩放至`[-1, 1]`区间；
5. 结果还原：将NaN还原为“未获取到信息”，保留无效值标识；
6. 输出结果：返回规范化后的数据集和缩放信息，打印每个字段的统计信息和前15条数据示例。

#### 7.3.4 处理结果
- 规范化后“总评论数”“阅读量”字段的数值均落在`[-1, 1]`区间内，例如“阅读量”最大绝对值`19800`，$j=5$，缩放因子`100000`，归一化后最大值`0.1980`；
- 缩放系数动态适配数据范围，无需人工干预，适用于数据范围未知的场景；
- 不改变数据的相对大小关系，仅进行量级缩放，简洁高效。

    'here', 'there', 'when', 'where', 'why', 'how', 'very', 'too', 'so', 'just', 'almost',
    '未获取到信息', 'request', 'failed', 'parse', 'error', 'content', 'comment', 'unknown', 'user'
}

# 动词/形容词后缀（辅助筛选纯名词）
VERB_ADJ_SUFFIX = ['ing', 'ed', 'en', 'able', 'ible', 'ful', 'less', 'ive', 'ous', 'ly']

class WordCloudChartSpider(Spider):
    name = 'discussion_Word_cloud_chart_spiders'
    
    # 路径配置
    input_csv_path = os.path.join('data', 'csv', 'discussion_Detailed_Page_cleaned.csv')
    output_img_path = os.path.join('data', 'images', 'content_comment_nouns_top10_en.png')
    comment_separator = '|||'  # 评论分隔符
    
    def start_requests(self):
        # 检查输入文件
        if not os.path.exists(self.input_csv_path):
            self.logger.error(f"输入CSV不存在：{self.input_csv_path}")
            return
        
        # 读取CSV（仅保留正文和评论字段）
        try:
            df = pd.read_csv(
                self.input_csv_path,
                encoding='utf-8-sig',
                usecols=['清洗后的正文内容', '清洗后的评论内容列表']
            )
            self.logger.info(f"读取到 {len(df)} 条有效记录")
        except Exception as e:
            self.logger.error(f"读取CSV失败：{str(e)}")
            return
        
        # 提取纯名词
        content_nouns = self._extract_nouns(df['清洗后的正文内容'], is_content=True)
        comment_nouns = self._extract_nouns(df['清洗后的评论内容列表'], is_content=False)
        
        # 生成可视化图表
        self._generate_chart(content_nouns, comment_nouns)
        
        # 打印Top10名词
        self._print_top10_nouns(content_nouns, comment_nouns)
        
        self.logger.info(f"纯名词图表已保存：{os.path.abspath(self.output_img_path)}")
        return
    
    def _extract_nouns(self, text_series, is_content):
        """提取文本中的纯名词（无nltk依赖）"""
        # 过滤无效文本
        invalid_text = ['', ' ', '未获取到正文内容', '未获取到评论内容', '请求失败', '解析失败',
                       'No content', 'No comments', 'Request failed', 'Parse error']
        valid_text = text_series.dropna().loc[~text_series.isin(invalid_text)]
        
        # 合并文本（处理评论列表拆分）
        if not is_content:
            clean_comments = []
            for comment_str in valid_text:
                for c in comment_str.split(self.comment_separator):
                    clean_c = re.sub(r'^[^:]+:\s*', '', c).strip()  # 移除用户名前缀
                    clean_comments.append(clean_c)
            combined_text = ' '.join(clean_comments)
        else:
            combined_text = ' '.join(valid_text.tolist())
        
        # 文本清洗：小写+移除非字母+拆分单词
        combined_text = combined_text.lower()
        combined_text = re.sub(r'[^a-zA-Z\s]', ' ', combined_text)  # 仅保留字母和空格
        words = combined_text.split()
        
        # 筛选纯名词
        nouns = []
        for word in words:
            # 条件1：排除非名词表中的词
            if word in NON_NOUNS:
                continue
            # 条件2：长度≥2（排除单字母）
            if len(word) < 2:
                continue
            # 条件3：排除动词/形容词后缀
            if any(word.endswith(suffix) for suffix in VERB_ADJ_SUFFIX):
                continue
            # 条件4：排除纯数字
            if word.isdigit():
                continue
            nouns.append(word)
        
        # 统计词频
        return dict(Counter(nouns))
    
    def _generate_chart(self, content_nouns, comment_nouns):
        """生成正文VS评论Top10纯名词柱状图"""
        # 创建输出目录
        os.makedirs(os.path.dirname(self.output_img_path), exist_ok=True)
        
        # 提取Top10名词
        content_top10 = Counter(content_nouns).most_common(10)
        comment_top10 = Counter(comment_nouns).most_common(10)
        
        # 画布设置（1行2列）
        fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(16, 8))
        fig.suptitle('正文VS评论Top10纯名词（英文）', fontsize=20, fontweight='bold', y=0.95)
        
        # 绘制正文Top10名词（水平柱状图）
        if content_top10:
            words = [w[0] for w in content_top10][::-1]  # 逆序排列（词频从高到低）
            counts = [w[1] for w in content_top10][::-1]
            ax1.barh(words, counts, color='#009688', alpha=0.8)
            ax1.set_title('正文Top10纯名词', fontsize=16, fontweight='bold')
            ax1.set_xlabel('出现次数', fontsize=12)
            # 标注数值
            for i, c in enumerate(counts):
                ax1.text(c + 0.2, i, str(c), va='center', fontsize=10)
        else:
            ax1.text(0.5, 0.5, '无有效名词数据', ha='center', va='center', fontsize=14)
            ax1.set_title('正文Top10纯名词', fontsize=16, fontweight='bold')
        
        # 绘制评论Top10名词（水平柱状图）
        if comment_top10:
            words = [w[0] for w in comment_top10][::-1]
            counts = [w[1] for w in comment_top10][::-1]
            ax2.barh(words, counts, color='#FF5722', alpha=0.8)
            ax2.set_title('评论Top10纯名词', fontsize=16, fontweight='bold')
            ax2.set_xlabel('出现次数', fontsize=12)
            # 标注数值
            for i, c in enumerate(counts):
                ax2.text(c + 0.2, i, str(c), va='center', fontsize=10)
        else:
            ax2.text(0.5, 0.5, '无有效名词数据', ha='center', va='center', fontsize=14)
            ax2.set_title('评论Top10纯名词', fontsize=16, fontweight='bold')
        
        # 保存图片
        plt.tight_layout(rect=[0, 0, 1, 0.92])
        plt.savefig(self.output_img_path, dpi=300, bbox_inches='tight', facecolor='white')
        plt.close()
    
    def _print_top10_nouns(self, content_nouns, comment_nouns):
        """打印Top10名词及词频"""
        self.logger.info("\n===== 正文Top10纯名词（英文） =====")
        content_top10 = Counter(content_nouns).most_common(10)
        if content_top10:
            for idx, (word, count) in enumerate(content_top10, 1):
                self.logger.info(f"{idx}. {word} - {count}次")
        else:
            self.logger.info("无有效正文名词")
        
        self.logger.info("\n===== 评论Top10纯名词（英文） =====")
        comment_top10 = Counter(comment_nouns).most_common(10)
        if comment_top10:
            for idx, (word, count) in enumerate(comment_top10, 1):
                self.logger.info(f"{idx}. {word} - {count}次")
        else:
            self.logger.info("无有效评论名词")
