## 9. 详情页文本特殊符号过滤
### 9.1 方法原理
详情页文本（正文+评论）中包含HTML标签、特殊符号（如@、#、￥、笑脸图标）、转义字符等冗余信息，需通过正则过滤和文本清洗，仅保留中文、英文、数字、常用标点（.，。！？；;:"''（）-=_+[]{}、·…—）及空格、小数点，确保文本数据的纯净性，为后续词云图绘制等分析提供高质量输入。

### 9.2 核心代码
```python
import re

class DiscussionDetailedPageSpider(Spider):
    # 特殊字符过滤正则：仅保留中文、字母、数字、常用标点、空格、小数点
    ALLOWED_CHARS_PATTERN = r'[^\u4e00-\u9fa5a-zA-Z0-9\s\.,，。！？；;:""''（）\(\)-_=+\[\]{}、·…—]'
    
    def clean_text(self, text):
        """
        清洗文本核心方法：
        1. 移除HTML标签
        2. 处理转义字符
        3. 过滤特殊符号
        4. 清理多余空格和换行
        5. 处理空值
        """
        if not text or text.strip() == '':
            return '未获取到信息'
        
        # 1. 移除HTML标签（如<div>、<p>等）
        html_pattern = r'<[^>]+>'
        text_without_html = re.sub(html_pattern, '', text)
        
        # 2. 移除转义字符（如\u003c、\\n等）
        text_unescaped = (
            text_without_html
            .replace('\\u003cp\\u003e', '')
            .replace('\\u003c/p\\u003e', '\n')
            .replace('\\u003cbr\\u003e', '\n')
            .replace('\\u003ccode\\u003e', '`')
            .replace('\\u003c/code\\u003e', '`')
            .replace('\\n', '\n')
            .replace('\\', '')
        )
        
        # 3. 过滤特殊符号（保留允许的字符，移除其余所有字符）
        cleaned_text = re.sub(self.ALLOWED_CHARS_PATTERN, '', text_unescaped)
        
        # 4. 清理多余空格和换行（将多个连续空格/换行合并为单个）
        cleaned_text = re.sub(r'\s+', ' ', cleaned_text).strip()
        
        # 5. 处理清洗后为空的情况
        return cleaned_text if cleaned_text else '未获取到信息'
```

### 9.3 实现步骤
1. **HTML标签移除**：使用正则表达式`r'<[^>]+>'`匹配所有HTML标签（如`<div>`、`<p>`、`<br>`）并删除，避免标签干扰文本分析。
2. **转义字符处理**：针对性替换Unicode转义字符（如`\\u003c`）和换行符（`\\n`），还原文本原始格式。
3. **特殊符号过滤**：通过`ALLOWED_CHARS_PATTERN`正则，仅保留中文、英文、数字及常用标点，过滤@、#、￥、笑脸图标、特殊符号（如^、&、*等）。
4. **冗余空格清理**：将多个连续的空格、换行合并为单个空格，去除文本首尾多余空格，规范文本格式。
5. **空值兜底**：若清洗后文本为空，统一返回“未获取到信息”，保证数据格式一致性。

- 清洗后的文本仅保留有效信息，例如原评论“@user 这是Fedora的更新问题！#Linux 🎉”，清洗后变为“user 这是Fedora的更新问题 Linux”。
