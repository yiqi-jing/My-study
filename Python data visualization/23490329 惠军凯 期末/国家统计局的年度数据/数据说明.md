## 数据格式说明

### 文件结构

每个CSV文件包含以下结构：

```
第1行: 数据库名称（年度数据）
第2行: 时间信息
第3行: 列标题（指标, 2025年, 2024年, ..., 2016年）
第4行起: 具体指标数据
```

### 列说明

- **第1列**: 指标名称（如"国内生产总值 (亿元)"）
- **第2-11列**: 年份数据（2025年, 2024年, 2023年, 2022年, 2021年, 2020年, 2019年, 2018年, 2017年, 2016年）
- 数据按时间倒序排列（最新年份在前）

### 数据特点

1. **时间序列数据**: 每个指标包含10年的连续数据
2. **缺失值**: 部分指标在某些年份可能没有数据，表示为空值
3. **单位标注**: 指标名称中包含计量单位，如"(亿元)"、"(万人)"等
4. **数据精度**: 数值保留不同精度，根据统计要求而定

## 主要数据类别

### 1. 宏观经济指标（年度数据 (2).csv）

- **国内生产总值 (GDP)**
  - GDP总量（亿元）
  - 人均GDP（元）
  - GDP增长率（%）
  
- **产业结构**
  - 第一产业增加值（亿元）
  - 第二产业增加值（亿元）
  - 第三产业增加值（亿元）
  - 三次产业占比（%）

- **国民收入**
  - 国民总收入（亿元）
  - 国民总收入指数

### 2. 人口统计指标（年度数据 (3).csv）

- **人口总量**
  - 年末总人口（万人）
  - 城镇人口（万人）
  - 乡村人口（万人）
  
- **人口变动**
  - 人口出生率（‰）
  - 人口死亡率（‰）
  - 人口自然增长率（‰）

- **就业数据**
  - 就业人员总数（万人）
  - 城镇就业人员（万人）
  - 乡村就业人员（万人）

### 3. 居民收入与消费（年度数据 (4).csv）

- **居民收入**
  - 居民人均可支配收入（元）
  - 城镇居民人均可支配收入（元）
  - 农村居民人均可支配收入（元）

- **居民消费**
  - 居民人均消费支出（元）
  - 食品烟酒支出（元）
  - 衣着支出（元）
  - 居住支出（元）
  - 教育文化娱乐支出（元）

### 4. 能源数据（年度数据 (5).csv）

- **能源生产**
  - 能源生产总量（万吨标准煤）
  - 原煤产量（万吨）
  - 原油产量（万吨）
  - 天然气产量（亿立方米）

- **能源消费**
  - 能源消费总量（万吨标准煤）
  - 电力消费量（亿千瓦小时）

### 5. 对外贸易（年度数据 (6).csv）

- **进出口总额**
  - 进出口总额（人民币）（亿元）
  - 出口总额（人民币）（亿元）
  - 进口总额（人民币）（亿元）
  - 贸易顺差/逆差（亿元）

### 6. 金融数据（年度数据 (7).csv）

- **货币供应**
  - 货币供应量M0、M1、M2

- **信贷数据**
  - 各项存款余额
  - 各项贷款余额

### 7. 社会数据（年度数据 (8).csv - (14).csv）

- **法人单位**: 企业、机关、事业单位数量
- **教育文化**: 学校数、在校生数、文化机构数
- **医疗卫生**: 医院数、床位数、卫生技术人员数
- **社会保障**: 参保人数、社保基金收支
- **环境保护**: 环保投入、污染物排放
- **科技创新**: R&D投入、专利申请数
- **基础设施**: 公路里程、铁路里程、港口吞吐量

## 数据使用说明

### 数据读取

```python
import pandas as pd

# 读取CSV文件
df = pd.read_csv('年度数据 (2).csv', encoding='utf-8', skiprows=2, header=None)

# 设置列名
years = ['2016年', '2017年', '2018年', '2019年', '2020年', 
         '2021年', '2022年', '2023年', '2024年', '2025年']
df.columns = ['指标'] + years + ['备注']

# 数据清洗
for year in years:
    df[year] = pd.to_numeric(df[year].astype(str).str.replace(',', '').str.strip(), errors='coerce')
```

### 数据特点

1. **权威性**: 数据来源于国家统计局，具有官方权威性
2. **完整性**: 涵盖经济社会发展的各个方面
3. **连续性**: 10年时间序列数据，便于趋势分析
4. **可比性**: 统计口径一致，年度间可比
5. **时效性**: 包含最新统计数据（截至2025年）

### 注意事项

1. **数据更新**: 部分最新年份数据可能为初步统计数，后续可能修订
2. **缺失值处理**: 某些指标在某些年份可能没有数据，需要合理处理
3. **单位换算**: 注意指标单位，必要时进行换算
4. **统计口径**: 部分指标统计口径可能发生变化，需注意说明
5. **数据解读**: 结合经济社会发展背景正确解读数据
